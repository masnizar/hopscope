How to capture a traffic trace

  • EnableSCC UI → Log and Trace Files → Edit → enable Payload Trace for the relevant subaccount. If the four-eyes principle is active, a second user must approve.
  • ReproduceRun the failing scenario (BTP application → destination → SCC → backend) and note the time.
  • CollectDownload tunnel_traffic_*.trc from the Log and Trace Files page (or the log/ folder of the SCC installation), then disable the payload trace again.
  • Sensitive dataTraffic traces contain business data, cookies, tokens and authorization headers. Files are processed only in this browser; sensitive header values are masked by default.
  • End-to-end HTTPSIf SCC calls the backend via HTTPS, the trace contains encrypted TLS data that cannot be decoded.
