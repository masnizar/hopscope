How to collect each source (same time range)

  • Web Dispatcherdev_webdisp from the work directory of the Web Dispatcher instance (or web administration → Monitor → Trace).
  • ICM (SMICM)SMICM → Goto → Trace Level → 2 (3 for TLS handshake details) → Goto → Trace File → Reset → reproduce → Goto → Trace File → Display All → save as local file, or dev_icm via AL11 / CG3Y. Any name containing dev_icm works (e.g. DV1_dev_icm.txt). Set the level back afterwards.
  • Cloud ConnectorSCC UI → Configuration → Log And Trace Files → set the Cloud Connector loggers to All → reproduce → download ljs_trace.log / scc_core (or "Download All" as .zip) → reset the level. Backend requests, system mappings and principal propagation are only logged at that level.
  • Time zonesSCC logs in UTC, SAP traces in server time. The server offset is detected from the HTTP Date: … GMT headers in dev_icm / dev_webdisp and the SCC times are converted; override with "Server time zone".
  • dev_w* / dev_dispSM50 → select work process → Administration → Trace → Display File (save), or AL11 → DIR_HOME.
  • SM21Select the time range → list → Export → Spreadsheet (.xlsx) or Local File → Text with Tabs. Keep the column headers (Date, Time, Message Text, …).
  • ST22Select the time range → dump list → Export → Spreadsheet or Text with Tabs (columns Date, Time, Runtime Error, Exception, Program, User…).
  • SM59Connection Test of the destination → System → List → Save → Local File (or copy the result into a .txt file). Without a timestamp the file date is used.
  • STRUSTDouble-click the certificate → Export (.crt/.cer/.pem), or copy the certificate details / sapgenpse maintain_pk -l output into a .txt file.
  • PrivacyEverything is processed locally in this browser.
